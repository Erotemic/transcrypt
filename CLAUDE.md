# Transcrypt development guidance

Read [AGENTS.md](AGENTS.md) and
[docs/verification/V3-PRODUCT-CHARTER.md](docs/verification/V3-PRODUCT-CHARTER.md)
before changing the v3 implementation, proof claims, security requirements or
Git workflow. Follow the charter's distinction between public-Git security,
ordinary unlocked-local use, and optional workstation privacy. A finished task
is a checkpoint: continue to the next evidence-backed improvement when useful.

For current implementation status and proof assumptions consult
[the v3 handoff](docs/verification/V3-HANDOFF.md),
[the proof ledger](docs/verification/V3-PROOF-COVERAGE.md), and
[the assumption register](docs/verification/V3-ASSUMPTIONS.md).
